# Outputs (Hackathon Submission)

This folder contains the final outputs generated by the Disaster Zone Aerial Assessment System.

These artifacts demonstrate how aerial disaster video is transformed into actionable geospatial intelligence.

---

## Included Artifacts

### 🎥 Demo Video
- End-to-end system demonstration
- Shows full pipeline:
  video input → AI analysis → damage detection → blocked road identification → map-ready outputs

### 📄 Sample Results Report
- Example structured disaster assessment output
- Includes:
  - Damage classification and severity
  - Blocked roads and access constraints
  - Resource requirements for emergency response
  - Financial damage estimation

### 🗺️ (Optional) Geospatial Output
- GeoJSON files representing:
  - Damage locations
  - Road blockages
  - Affected infrastructure zones
